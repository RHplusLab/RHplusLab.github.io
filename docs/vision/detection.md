# Object Detection

!!! abstract "요약"
    - 경기장 목표물은 **색으로 구분**된다 (파란 허들 · 보라 허들 · 분홍 골대 · 초록 골대) → 딥러닝 없이 **HSV 색상 필터링**으로 인식
    - 출력: 목표물 중심 · 크기 → 거리 → 카메라 좌표계 3D 좌표 → 정렬 오차 (ΔX · ΔY · Δθ)
    - 진행: Phase 0~3 (카메라 좌표계 3D 좌표) 완료, 로봇 좌표계 변환 · 필터링 미구현 → [진행 단계](index.md#phases)

!!! note "설계 단계"
    인식 코드는 GitHub 저장소에 아직 없다. 아래 처리 단계는 기존 대회 수상 팀 보고서 분석과 작업 기록을 정리한 것이며, 임계값 · 허용 오차는 계획값이다.

## 인식 대상

| 미션 | 대상 | 색 |
|---|---|---|
| ① 허들 (5 cm) | 허들 | 파랑 |
| ② 농구 | 공 (지름 7 cm 스펀지) · 골대 입구 | 골대: 분홍 |
| ③ 허들 (10 cm) | 허들 | 보라 |
| ④ 축구 | 바닥의 공 · 골대 입구 | 골대: 초록 |
| 공통 | 바닥 유도선 (경로 이탈 확인) | 흰색 점선 |

경기장 규격 → [Task Generation › 경기장 코스](../task/index.md)

## 처리 단계

```text
/image_flipped/compressed
   │
   ▼
① HSV 변환 · 색상 범위 마스크
② Closing   — 마스크 안의 구멍 메우기
③ Opening   — 작은 잡음 점 제거
④ 윤곽선 검출
⑤ 면적 필터링 — 너무 작은 윤곽선 제외
⑥ 가장 큰 윤곽선 선택
⑦ Bounding Box 계산
⑧ 중심점 계산
   │ (u, v), 폭 · 높이 [px]
   ▼
거리 추정 → 3D 좌표 → 정렬 오차
```

| 단계 | 이유 |
|---|---|
| HSV | RGB보다 조명 밝기 변화에 강함 — 색상(H)과 밝기(V)가 분리됨 |
| Closing → Opening | 반사 · 그림자로 생긴 구멍을 먼저 메우고, 배경의 같은 색 잡음 점을 지움 |
| 면적 필터 · 최대 윤곽선 | 같은 색 물체가 화면에 하나뿐이라는 가정 — 가장 큰 덩어리를 목표물로 봄 |

- 시뮬레이션 영상은 해상도가 다름 (320 × 200) → 면적 임계값은 해상도에 비례해 조정 → [Camera Setup › Gazebo 카메라](camera.md)

## 거리 추정 { #distance }

| 방법 | 원리 | 필요한 값 |
|---|---|---|
| Bounding Box 크기 | 실제 크기를 아는 물체는 멀수록 작게 보임 → 거리 ≈ 초점거리 × 실제 크기 / 픽셀 크기 | 카메라 초점거리(intrinsics), 물체 실제 크기 |
| 카메라 pitch + 픽셀 위치 | 바닥에 놓인 물체는 화면 아래쪽일수록 가까움 → 카메라 높이 · 기울기와 픽셀 행(v)으로 바닥 교점 계산 | 카메라 높이, `head_tilt` 각도, intrinsics |

- 두 방법 모두 **카메라 캘리브레이션(Phase 1)이 먼저** 필요 — 초점거리 · 광학 중심 · 렌즈 왜곡
- 거리와 픽셀 중심 → 카메라 좌표계(`cam_link`) 3D 좌표 (Phase 3)
- 로봇 좌표계 변환(Phase 4): `cam_link` → `head_tilt_link` → … → `body_link` TF 체인 사용 → [Camera Setup › 카메라 좌표계](camera.md)

## 정렬 오차 → 동작

인식 결과는 Task Generation의 **정밀 정렬(Fine Alignment)** 에서 쓰인다.

| 오차 | 의미 | 보정 동작 | 허용 범위 (허들 기준) |
|---|---|---|---|
| ΔY | 좌우 어긋남 | 옆걸음 (1 cm 단위) | ±2 cm |
| ΔX | 목표 거리와의 차이 | 앞 · 뒤 걸음 (1 cm 단위) | 15~20 cm 거리 |
| Δθ | 정면 각도 어긋남 | 제자리 회전 (2~3° 단위) | ±5° |

```text
인식 → 오차 계산 → ΔY 보정 → ΔX 보정 → Δθ 보정 → 다시 인식 → 모두 만족하면 동작 실행
```

- 한 번에 한 축씩 보정하고 매번 다시 인식
- 미션별 허용 오차 · 전체 순서도 → [Task Generation › 미션 상태 기계](../task/index.md)
